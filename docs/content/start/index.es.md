# Empiece aquí

Tres capítulos cortos le dan el panorama completo antes de entrar en detalles:

1. **[Por qué existe rendimiento](vision.md)**: el problema que reemplazó, las decisiones que le dieron forma y la historia de cómo sus aplicaciones se mudaron a él.
2. **[Conceptos y vocabulario](concepts.md)**: la docena de palabras que usa el resto del libro (aplicación, servicio, ejecución, versión, complemento, necesidad…) y cómo se relacionan.
3. **[Un recorrido por la interfaz](tour.md)**: cada página del panel y para qué sirve.

Después, elija la parte del libro que corresponda a lo que quiere hacer: administrarlo ([Su entorno](../environment/index.md)), entenderlo ([Arquitectura](../architecture/index.md)), usarlo ([Uso](../guide/index.md)), cambiarlo ([Desarrollo](../develop/index.md)) o hacerlo crecer ([Crecimiento](../future/index.md)).
